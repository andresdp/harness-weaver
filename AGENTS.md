# Project instructions

## Python environment

- Use the `harness` Conda environment for Python commands in this repository.
- Run commands as `conda run -n harness python ...` (and use `conda run -n harness python -m pip ...` for package operations).
- Install this project and its declared dependencies in that environment with `conda run -n harness python -m pip install -e .` before running the `hw` command or Python unit tests.
- Do not use the system Python or another Conda environment for project validation.
