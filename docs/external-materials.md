# External materials and case studies

This page credits the external projects and research used to inform HarnessWeaver pilots. Full-text papers and external case-study snapshots are kept in local ignored directories only; they are not distributed by this repository's MIT license. Follow each source's own terms when obtaining or using its materials.

## Generation-skill antecedent

- **Revfactory/harness v2.1.0** — upstream Claude Code skills that informed the HarnessWeaver `harness` and `evolve` generation skills. Source: [GitHub repository](https://github.com/revfactory/harness). The repository retains selected upstream materials and an English translation under Apache-2.0 in `baselines/`; see [THIRD-PARTY-NOTICES.md](../THIRD-PARTY-NOTICES.md) for attribution and scope.

## Architecture-evaluation case study

- **ArchEval: “Agents as Architecture Evaluators: Automating ATAM and SAAM for Continuous Assessment.”** Adyansh Kakran, Sathvika Miryala, and Karthik Vaidhyanathan, ASE 2026 AgenticDev Workshop extended abstract. [ACM DOI](https://doi.org/10.1145/3843282.3844431). The external replication package contains prior human architecture evaluations and an agentic evaluation workflow. Its local snapshot under `case-studies/architecture-eval/` is ignored and excluded from the repository tree; cite the paper and obtain any data or code from its authors or official release.

## Architecture-design case study

- **Software Architecture Agent (SARA).** The pilot is informed by the upstream project at [NicolasMP51/software-architecture-agent](https://github.com/NicolasMP51/software-architecture-agent). The local clone is ignored; this repository keeps only HarnessWeaver-authored mappings and pilot configuration where included.
- **ReArch: “Architecture Exploration and Reflection meet LLM-based Agents.”** J. A. Díaz-Pace, A. Tommasel, R. Capilla, and Y. E. Ramírez, ICSA 2025 New and Emerging Ideas Track. This work is cited as the prior architecture-exploration workflow informing the design-exploration direction. Its local PDF copy under `papers/` is not part of the repository tree.
- **Better Together: “An LLM-assisted approach to designing software architectures using Attribute-Driven Design.”** H. Cervantes, R. Kazman, and Y. Cai, *IEEE Transactions on Software Engineering*, 2026. [IEEE Xplore](https://doi.org/10.1109/TSE.2026.3706446).
