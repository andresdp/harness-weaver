Analyze the supplied architecture evidence using the ATAM concepts and source materials referenced by the evaluation skill.

## Procedure

1. Refine each stated quality attribute into a scenario with a stimulus, environment, response, and measurable response measure where the sources permit it.
2. Record priority tuples only when the input supports stakeholder judgments; otherwise mark priority as unresolved.
3. Identify architectural approaches from explicit design evidence. Separate observed decisions from inferred possibilities.
4. Analyze prioritized scenarios against relevant approaches and evidence.
5. Record risks, non-risks, sensitivity points, and tradeoff points with rationale and evidence references.

Return structured findings for the facilitator. Every claim must carry a source reference or be marked as an assumption, inference, or open question.
