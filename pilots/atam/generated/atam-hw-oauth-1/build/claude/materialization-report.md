## Decisions

| Decision | Choice | Rationale | Gate |
|---|---|---|---|
| Execution mode | Sub-agent delegation, file data passing | Fixed pipeline with no agent-to-agent negotiation; needs no Workflow tool; maps 1:1 to DeepAgents | G5 |
| Model tiering | opus: utility tree, approaches, analysis, review; sonnet: context extraction, report projection | Deep judgment vs. procedure-following; rationale in each agent's frontmatter comment | G5 |
| Stage 2 ∥ stage 3 | Parallel `Agent` calls in one message | Both depend only on 00/01 | G2 (spec workflow) |
| Deterministic checks | `check-evaluation/scripts/validate_artifacts.py` (stdlib) | Spec V1–V8 need code-level checks; no third-party install required | G3 |
| Revision | One cycle: synthesizer revises, reviewer re-checks | Design notes: bounded cost; remaining failures stay visible | G2 |
| `reviewed` status | Only with `_workspace/architect_review.json` from a user-supplied architect review | G3 answer: never by the harness | G3 |
