## Decisions

| Decision | Choice | Rationale | Gate |
|---|---|---|---|
| Agent-to-agent messaging | None needed; artifacts only | The design has no messaging | D2 default |
| Human confirmation points | Dropped from the runtime; H1 listed in `wiring.yaml` | HITL = none | G5 |
| Adversarial/independent verification | Intra-agent `check-evaluation` task + one `revise-report` pass | Subagents disallowed | G5 / D2 default |
| Model tiers | Single env-driven model (`openai:gpt-5.4-mini`); tier rationale kept as an HTML comment in each `AGENTS.md` | Host uses one model | G5 / D2 default |
| Structured schemas | JSON structure block per skill + full schema in each skill's `references/` + `contracts/` for the host | Agreement between blocks and schemas comes from one template source | D2 default |
| Spec input port | Host writes `/artifacts/00_evaluation_inputs.json` | — | D2 default |
| Deterministic validator | Not shipped (stages cannot run code) | The Claude target ships it; here the host's schema validation is the only code check | D2 |
