## Harness: ATAM architecture evaluation

**Goal:** Produce an evidence-grounded ATAM evaluation draft of a supplied software architecture for review by a software architect.

**Invocation conditions:** When asked to evaluate a software architecture with ATAM, produce or re-run an ATAM report, or redo, re-review or revise part of a previous evaluation, use the `atam-orchestrator` skill. Simple questions about ATAM or about an existing report may be answered directly.
