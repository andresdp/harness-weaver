## Harness: SARA architecture design

**Goal:** From a project description and its functional requirements, produce one evidence-backed architecture recommendation documented as an ADR and a high-level component diagram, for review by a software architect before use.

**Trigger conditions:** When asked to design or recommend a software architecture from requirements, derive drivers or alternatives, or produce an ADR and component diagram (including re-runs and revisions of earlier results), use the `sara-architecture-orchestrator` skill. Simple questions may be answered directly.
