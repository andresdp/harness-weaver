## Decisions

| Decision | Choice | Rationale | Gate |
|---|---|---|---|
| Execution mode | Sub-agent delegation, serial, foreground; deterministic schema gate between stages | Fixed four-stage pipeline with no inter-agent dialogue. Runs in any Claude Code session without the `Workflow` tool or extra consent. | G5 (user, live) |
| Models | Not pinned; agents inherit the session model | Keeps the Claude arm comparable with other arms run on the same model (RUNBOOK); matches the DeepAgents decision "not pinned". | G5 (user, live) |
| Output location | `generated/build/claude/` | Package workflow default. | G4 / G6 (user, live) |
| Stage granularity | One agent per spec stage; tasks run inside the agent | Preserves SARA's stage boundaries and the "one stage orchestrator runs its ordered tasks" shape. | from spec |
| Artifact location | `_workspace/artifacts/<artifact>.json` | Claude Code harness convention (`_workspace/`) + A4 single location; SARA filenames kept, as in the spec. | target mapping |
| Retry budget | One repair re-invocation of the stage agent per failed gate, with the exact validator output; a second failure stops the pipeline | Claude Code guidance (retry once). The spec declares no retry count. Later stages cannot proceed on invalid inputs. | target mapping |
| Validator unavailable | Stop (exit 2), do not continue unverified | Keeps v-stage*-schemas deterministic. | target mapping |
| Follow-up runs | Step 0: restart at the earliest affected stage, then re-run all later stages; superseded artifacts are moved aside | Every later stage depends on earlier artifacts; avoids stale files passing a gate. | target mapping |
| Agent tools | `Read, Write, Edit, Bash, Glob`; no `Agent` tool | Bash for the schema check, Edit for repairs; no nested sub-agents (spec has no subagents). | target mapping |
| Methodology reference | `references/methodology.yaml` copied verbatim | Self-contained bundle. Its Stage 4 inputs and outputs predate A6/A7; the orchestrator states that the spec adaptations apply. | target mapping |

## Manual setup required

- Run Claude Code with `generated/build/claude/` (or a copy of it) as the project directory, so `.claude/agents/`, `.claude/skills/` and `CLAUDE.md` load.
- `python3` with `jsonschema` (4.x, Draft 2020-12 support) on `PATH`. Without it the gate exits 2 and the pipeline stops.
- Permissions for `Bash(python3 .claude/skills/sara-architecture-orchestrator/scripts/validate_stage.py:*)`, `Bash(mkdir:*)`, `Bash(mv:*)`, `Bash(cp:*)`, `Bash(date:*)`, and writes under `_workspace/` and `output/` (or approve them when prompted).
- Optionally set the model with `--model` / `MODEL`. Agents inherit it.
